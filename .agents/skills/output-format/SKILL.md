---
name: output-format
description: Output rules for every pipeline step. Follow together with the step skill whenever the Master assigns a pipeline step.
---

- 해당 스킬의 Input에 명시된 파일 외에는 읽지 않는다.
- 모든 결과 파일은 영어로 쓴다.
- 각 출력 스키마의 키 이름과 순서, 중첩 구조, 들여쓰기, 줄 배치, 블록형·흐름형 표기를 그대로 따른다. 단, Dynamic IR의 문자열 값 내부에서는 설명의 길이에 따라 줄바꿈 위치와 줄 수를 조정할 수 있다. 스키마에 없는 키를 추가하거나 기존 키를 삭제·변경하지 않는다.
- 스키마에서 여러 줄로 배치한 항목이나 목록을 한 줄로 합치지 않는다. 속성을 한 줄씩 나열한 경우에는 각 속성을 별도의 줄에 유지한다. 출력을 JSON으로 바꾸지 않는다.
- Dynamic IR의 문자열 값은 스키마처럼 해당 하위 키의 다음 줄에서 들여써서 시작하고, 이어지는 내용도 같은 들여쓰기의 연속 줄에 작성한다. 각 말단 값은 하나의 YAML 문자열로 유지한다. 추가 guard가 없어 빈 문자열로 쓰는 경우에는 guard: ""로 작성한다. 다른 출력의 문자열 값은 해당 키와 같은 물리적 줄에 작성하고 다음 줄로 나누지 않는다.
- YAML 블록 문자열 표기인 `>`와 `|` 및 그 모든 변형(`>-`, `>+`, `|-`, `|+`, 들여쓰기 숫자가 붙은 형태 등)을 사용하지 않는다.
- 파이썬 등으로 파일을 생성하거나 YAML을 읽고 다시 저장하더라도, 라이브러리나 자동 정렬 도구의 기본 설정 때문에 위 형식이 바뀌어서는 안 된다.
- 스키마의 `#` 주석은 작성 지침이다. 주석의 내용은 출력 파일에 쓰지 않는다. 주석 형태로도, 본문 문장으로도 쓰지 않는다.
- 해당 스킬의 Output에 적힌 파일만 만든다. 검증 스크립트, 테스트 파일, 로그 등 다른 파일을 만들지 않는다.
